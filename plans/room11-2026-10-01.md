## A bug the restart found: stale edge runs

The first run was killed in level 2 and the second ran a DIFFERENT level 2
(`r2sxhn`) in the same `h094/level02`. Each frame's checkpoint replaces its
own directory, but an edge run is one file per (layer, frame), so a run the
killed level wrote for a pair the new one did not survived, and the
backward read it against the new rows: `edges: marked id l79 s0 r64924 is
past its file's 64923 rows` (fatal, nothing wrong reported). Fixed:
`ForwardState::start` clears `frames/` and `edges/` (test
`a_fresh_forward_clears_what_a_killed_run_left`).
