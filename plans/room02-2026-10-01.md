# Room (0,2) "1700 m" (2026-10-01): exit at frame 81, ties TAS17

Room: spawn (16,104), springs (104,88) and (72,112), a fake wall (0,112)
with its fruit; no ice. The first room of map row 2.

## Two data bugs found on the way (5746919)

TAS17 never exited in the original cart at any offset: `cart/map-data.txt`
held map rows 32-63 (the cart's `__gfx__` half, nibble-swapped there) without
swapping them back, so every room of rows 2 and 3 was garbage (2-7 player
spawns a room) in our engine; and `pico8_diff/replay.py` wrote each such map
row as one 256-char gfx line, which PICO-8 truncates. Both fixed
(`every_level_room_has_one_player_spawn`). TAS17 then exits during frame 81
at offset 25; fitted to celeste-minimal (`tas/room_0_2_reference_frame_81.txt`).

## Level 0: springs, and the level -1 filter

`r0sxhn .. r4sxhn, r4sxh .. r15sxh, rxsx`. Unfiltered level 0 exploded with
the springs' speeds (`spd.x` 142 / 2511 / 6979 distinct values in the three
shapes - wall intact, broken, fruit out): 65.8M states at f75, x1.24 a frame,
300 s a frame. A speed-bucketed level 0 (`r0s16hn`) OOMed BUILDING its
kernels (60 GB). The level -1 table refused to build (an arity-2 move fork
over an interval speed spanning 5 floors: "not sound"); fixed with rooms
(6,1)/(7,1)'s table failures in `a932619`. With the filter
(`CELESTE_LEVEL_MINUS_ONE="81,5"`): f65 3.3M, f70 1.3M, f75 389k, 87M
visited, 5.4 GB peak.

## A spurious 80, a soundness bug, and the result

The first filtered run found first wins of 80 at every exact level, but the
witness found NO concrete chain (not even the known 81). `ref-check` at the
spawn frame (f25): the kernels put the new player in the AIR (grace 0, air
accel, gravity), the reference engine and PICO-8 on the ground. Root cause
(`52a368a`): `Graph::tile_flag_over` clamped a TOP coordinate's corner and
size separately, so a collision test over a wholly unknown `y` read tile row 0
only and folded to false. Room (0,2)'s spawn frame has no `y` range (its start
shape changes on the first frame). The same fold changed in rooms (7,0) and
(6,1) only (a diff of every fold, all rooms of rows 0-1): (7,0)'s result is
re-searched.

Fixed run (`--ceiling 81`, level -1 filter): h81 confirmed through Exact
(first wins 68 72 75 77 78 78 79 x5, 81 from rem Bits(10)); h80 refuted at
level 11 (Bits(10)). `OPTIMAL win frame: 81`. Witness 278 steps, 0 dead
ends; on a real PICO-8 f80 player (45,-3), f81 room (1,2)
(`tas/room_0_2_exit_frame_81.txt`). TIES TAS17.
